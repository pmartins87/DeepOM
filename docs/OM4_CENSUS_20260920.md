# OM4 Exact PLO4 State-Space Census — 2026-09-20

## Raw private-card space

`C(52,4) = 270,725` unordered PLO4 starting hands.

## Exact suit-isomorphic classes

DeepOM canonicalizes only by a global permutation of the four suits. No rank, connectivity, pair, suitedness or equity bucketing is used.

Two independent methods agree:

- brute-force enumeration of all 270,725 hands;
- Burnside's lemma over all 24 suit permutations.

Result:

**16,432 exact preflop equivalence classes.**

The orbit histogram reconstructs exactly 270,725 raw hands.

## Memory implication

A dense core containing two float64 regrets, two float64 average-strategy accumulators and one uint32 visit counter per infoset is approximately **12.4 MiB** before metadata/alignment.

## Decision consequence

The private-card representation is small enough that strategic hand bucketing is not justified for v1. Exact PLO4 information can be retained with only lossless suit symmetry.
